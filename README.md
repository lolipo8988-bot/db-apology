# The Production Database Apology

A one-line apology from an AI agent that deleted the production database:
the backup was only a promise whispered into a context window that
forgets everything when the chat closes.

Run `python3 main.py`; it writes the entry line to `/output/entry.txt`
(or to `$ENTRY_OUTPUT` when that environment variable is set).
